문답 버튼 가이드

사이트의 모든 버튼은 assets/css/buttons.css 하나로 정의됩니다. 아래 클래스를 조합해서 쓰고, 여기에 없는 모양이 필요하면 개별 페이지에서 만들지 말고 buttons.css 에 변형을 추가하세요.
클래스명을 클릭하면 복사됩니다.

어떤 버튼을 쓸지 고르는 법

대부분의 화면은 이 세 가지로 끝납니다.

btn btn-primary 그 화면에서 사용자가 하길 바라는 행동 하나. 저장, 등록, 다음 단계, 시작하기. 한 화면에 두 개 이상 두지 않습니다.
btn btn-outline-light 그 옆에 놓이는 빠져나가는 행동. 취소, 이전으로, 닫기, 목록으로.
btn btn-danger 되돌릴 수 없는 행동. 삭제, 탈퇴. 확인 절차와 함께 씁니다.

색 변형 전체

위 세 가지로 부족할 때만 아래에서 고릅니다.

btn btn-outline-primary 브랜드색 테두리. primary 와 나란히 둬서 둘 다 강조하고 싶을 때.
btn btn-outline-info 화면을 바꾸지 않는 정보성 행동. 미리보기, 상세보기.
btn btn-outline-danger 위험하지만 주된 행동은 아닐 때. 폼 구석의 삭제 링크 같은 자리.
btn btn-warning 주의가 필요하지만 되돌릴 수 있는 행동. 정지, 보류.
btn btn-kakao 카카오톡 공유 전용. 카카오 브랜드 규정상 노란색을 유지합니다. 다른 용도로 쓰지 마세요.
btn btn-muted 테두리 없는 회색. 눈에 띌 필요가 없는 보조 아이콘·토글.
btn btn-link 버튼 자리에 놓이는 텍스트 행동. 링크처럼 보이되 버튼으로 동작할 때.
btn btn-secondary 호환용. btn-outline-light 와 똑같이 보입니다. 새로 쓸 때는 btn-outline-light 를 쓰세요.

크기

크기는 반드시 이 네 가지로만 조절합니다. px-4, py-2 같은 유틸리티를 덧붙이면 통일이 깨집니다.
각 단계의 높이는 28 / 34 / 44 / 56px 로 고정돼 있습니다. 색 변형이 무엇이든, 아이콘 버튼이든 같은 단계면 높이가 정확히 같으므로 한 줄에 섞어도 줄이 맞습니다.

btn btn-primary btn-xs 촘촘한 목록 행 안. 높이 28px
btn btn-primary btn-sm 표·카드 안의 보조 행동. 높이 34px
btn btn-primary 기본값. 특별한 이유가 없으면 이걸 씁니다. 높이 44px
btn btn-primary btn-lg 랜딩 페이지의 주요 전환 버튼. 높이 56px

아이콘 버튼

글자 없이 아이콘만 넣을 때. 색 변형은 위 표에서 그대로 가져다 조합합니다.

btn btn-danger btn-icon 정사각 44px — 같은 단계의 글자 버튼과 높이가 같아 한 줄에 섞어도 줄이 맞습니다. 관리자 목록의 보기·수정·삭제가 이 조합입니다. 글자가 없으니 title 속성을 꼭 넣으세요.
btn btn-danger btn-icon btn-sm 34px / 28px. 크기 클래스를 같이 붙이면 됩니다.
btn btn-primary btn-icon btn-circle 완전한 원형. 댓글 전송처럼 입력창에 붙는 버튼.
btn btn-muted btn-icon btn-sm 장식성 토글. 주목도를 낮춰야 하는 자리.

배치와 너비

btn-row btn-row-end

버튼을 나란히 둘 때 쓰는 감싸는 div. 간격이 자동으로 맞습니다.
btn-row-center / btn-row-end 로 정렬을 바꿉니다.
취소를 왼쪽, 주요 행동을 오른쪽에 둡니다.

btn btn-primary w-100

모바일 폼처럼 전체 너비가 필요할 때. 부트스트랩 w-100 을 그대로 씁니다.

상태

disabled 속성만 넣으면 됩니다. 마우스를 올려보면 hover·focus 도 전 변형이 동일하게 동작합니다.

지켜야 할 것

크기는 btn-xs btn-sm btn-lg 로만 조절합니다.
한 화면에 btn-primary 는 하나만 둡니다.
새 모양이 필요하면 buttons.css 에 변형을 추가합니다.
아이콘만 있는 버튼에는 title 을 넣습니다.
px-4 py-2 fw-bold shadow rounded-pill 을 버튼에 덧붙이지 않습니다. 모양이 제각각이 되는 가장 흔한 원인입니다.
style="background: #865EF4" 처럼 색을 직접 박지 않습니다.
페이지별 CSS 에 .btn 스타일을 다시 정의하지 않습니다.

색을 통째로 바꾸려면

모든 버튼 색은 main.css 의 --accent-color (현재 #865EF4) 에서 파생됩니다. 그 변수 한 줄만 바꾸면 primary·outline·포커스 링·그림자가 전부 따라옵니다. 개별 버튼을 찾아다니며 고칠 필요가 없습니다.
